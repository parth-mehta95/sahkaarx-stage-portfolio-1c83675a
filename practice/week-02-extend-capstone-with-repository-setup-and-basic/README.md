# Extend Capstone with Repository Setup and Basic Commands

## Task Brief
Apply repository best practices and Git commands to add SQL query module with clean commit history.

## Scenario
Add a new SQL queries directory to your capstone repo following team standards and commit discipline.

## Deliverables
- New SQL module directory with sample queries
- 3-5 atomic commits with clear messages
- Updated README documenting module

## Success Criteria
- Repository structure is organized and documented
- Each commit has a meaningful, concise message
- All changes pushed to capstone repo main branch
