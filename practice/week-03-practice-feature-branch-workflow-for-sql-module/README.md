# Practice Feature Branch Workflow for SQL Module

## Task Brief
Create feature branches, make atomic commits, and prepare SQL query module for pull request review.

## Scenario
Your team is adding SQL query modules. Create a feature branch, commit query files atomically, and push for review.

## Deliverables
- Feature branch with 3-4 atomic commits
- SQL query module with sample queries
- Branch pushed to remote

## Success Criteria
- Each commit has clear, descriptive message
- Commits are logically separated by function
- Branch is ready for pull request
