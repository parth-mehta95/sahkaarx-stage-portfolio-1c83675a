# Practice SQL Queries in Capstone Repository

## Task Brief
Write SELECT, JOIN, and GROUP BY queries in Python scripts; commit to feature branch and push for review.

## Scenario
Your data team needs SQL query modules for multi-table analysis. Create feature branch, write production queries, and open pull request.

## Deliverables
- Python script with SELECT, JOIN, GROUP BY queries
- Feature branch with atomic commits
- Pull request for code review

## Success Criteria
- Queries retrieve data from multiple tables correctly
- Commits follow atomic commit conventions
- Pull request includes inline code comments
