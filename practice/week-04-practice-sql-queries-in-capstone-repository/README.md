# Practice SQL Queries in Capstone Repository

## Task Brief
Write SELECT, JOIN, and GROUP BY queries in Python scripts; commit to feature branch and push for review.

## Scenario
Your analytics team needs SQL query scripts in the capstone repo to extract and analyze sample data.

## Deliverables
- Python script with SELECT, JOIN, GROUP BY queries
- Feature branch with 3-4 atomic commits
- Query results documentation

## Success Criteria
- Queries execute without errors
- Commits follow atomic message standards
- Branch pushed to remote for review
