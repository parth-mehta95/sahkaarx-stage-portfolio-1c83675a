# Practice Feature Branch Workflow for Data Loading

## Task Brief
Create feature branch for data loading module; make multiple atomic commits; open pull request with inline comments; simulate peer review feedback; merge into main.

## Scenario
Your team needs a data loading module. Create a feature branch, commit changes atomically, and merge via pull request.

## Deliverables
- Feature branch with atomic commits
- Pull request with code review comments
- Merged feature branch in main

## Success Criteria
- Feature branch created and pushed
- Pull request opened with description
- Merge commit added to main
