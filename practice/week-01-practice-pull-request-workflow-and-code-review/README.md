# Practice Pull Request Workflow and Code Review

## Task Brief
Execute a complete pull request cycle: branch creation, commits, push, review feedback, and merge simulation.

## Scenario
Add a SQL query module to your capstone repo following team code review standards and collaborative merge practices.

## Deliverables
- Feature branch with 2-3 meaningful commits
- Pull request with inline code comments
- Merged commit to main branch

## Success Criteria
- All commits have clear, descriptive messages
- PR addresses at least one review comment
- Merge completed without conflicts
