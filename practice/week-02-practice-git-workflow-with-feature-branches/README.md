# Practice Git Workflow with Feature Branches

## Task Brief
Create feature branches, make commits using basic commands, and prepare for pull request review.

## Scenario
Your data team reviews code on feature branches before merging. Practice the full workflow with your capstone.

## Deliverables
- Feature branch with 3-4 meaningful commits
- Push to remote with branch tracking
- Branch ready for pull request review

## Success Criteria
- All commits use clear, descriptive messages
- Branch is up-to-date with main
- Remote branch reflects all local commits
