# Resolve Merge Conflicts in Capstone Repository

## Task Brief
Create conflicting branches, practice conflict resolution, and merge into main with documented commit messages.

## Scenario
Your team is working on SQL modules in parallel branches. Resolve conflicts and merge cleanly into main.

## Deliverables
- Feature branch with conflict markers resolved
- Merged commit with clear resolution message
- Updated capstone repo

## Success Criteria
- Conflicts identified and resolved correctly
- Commit history is clean and documented
- Main branch reflects all merged changes
