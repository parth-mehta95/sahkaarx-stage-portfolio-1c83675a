# Practice Conflict Resolution and Atomic Commits

## Task Brief
Create conflicting branches, practice conflict resolution, and merge into main with documented commit messages.

## Scenario
Simulate team collaboration by creating feature branches that intentionally conflict, then resolve and merge cleanly into main.

## Deliverables
- Feature branch with atomic commits
- Resolved merge conflict
- Merge commit with documentation

## Success Criteria
- Conflict resolved correctly
- Commit history is clean and atomic
- Merge commit explains resolution
